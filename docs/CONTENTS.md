# Content guide

Choose the question first, then the mathematical layer. For textbook numbering,
use [COVERAGE](COVERAGE.md); for dependency roles, use [ARCHITECTURE](ARCHITECTURE.md).

| Task | Entry |
| --- | --- |
| Reuse a probability tool | [Probability guide](../ECTheoryLib/Probability/README.md) |
| Apply drift to an abstract process | [Drift guide](../ECTheoryLib/Tools/Drift/README.md) |
| Turn a local transition inequality into runtime | [Local drift guide](LOCAL_DRIFT.md) |
| Read an algorithm’s definition and actual variant | [Algorithms](../ECTheoryLib/Algorithms/README.md) |
| Follow a completed algorithm/problem analysis | [Analysis](../ECTheoryLib/Analysis/README.md) |
| Run a small client or a source counterexample | [Examples](../Examples/README.md) |
